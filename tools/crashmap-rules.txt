# crashmap-rules.txt -- what the crash guard's step 1b (common/CrashStep.h) turns off when a SpringBoard crash points at one of our parts.
# Read by tools/make-crashmap.py at package time; the result (CrashMap.txt) ships next to the parts.
#
# target <name> pref <domain> <key> <off> <default> <row title>|<where>   a switch in Settings: set to <off> (0/1); <default> = its value when
#                                                     never set; the row's title and where the crash was, for the guard's explanation
# target <name> part                                  the part that crashed is not loaded in SpringBoard any more (until the guard's note is cleared)
# image <Image> <target> [map]                        what a crash in that part turns off; "map": a function map is built (the target is then the
#                                                     fallback for code no rule below names)
# sym <Image> <regex> <target>                        a function whose symbol name matches (Logos hooks carry their %group: $MacBanners$...)
# sec <Image> <regex> <target>                        a function whose first line sits under a matching section header (// ==== ... / // ---- ... /
#                                                     %group) in its source file; an "// ===== end ..." header ends a section
# file <Image> <regex> <target>                       a function from a matching source file
# Order: sym rules, then sec, then file, then the image's target; the first match wins. A switch that is already off falls back to "part".
# Every rule must match at least one function (make-crashmap.py stops the build otherwise): keep the section headers the sec rules name when
# comments are edited, or change the rule with them.
#
# Whenever a crash cannot be pinned on one of these (only Apple code on the stack, an unreadable report, one of the two loaders), the guard goes on
# to its step 2 (the whole tweak off) as before.

target part part
# transparent: a pass-through hook (-[UIApplication sendEvent:], -[UIResponder pressesBegan:withEvent:]): on nearly every touch and key stack,
# so it never decides a crash by itself (common/CrashBlame.h): any other non-Apple code below it is blamed instead, and step 1b passes over it
target transparent transparent
